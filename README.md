# IT Support Troubleshooting Guide

Beginner-friendly steps for common IT support issues.

## Windows computer connected to Wi-Fi but has no internet

1. Check whether other devices can access the internet.
2. Turn Wi-Fi off and back on, then reconnect.
3. Make sure Airplane mode is off.
4. Restart the computer.
5. If other devices are also offline, contact your internet provider or IT team.
6. If the issue continues on this computer only, note any error message and ask IT for help.

**Tip:** Don’t factory-reset the router unless your internet provider or IT team tells you to.
